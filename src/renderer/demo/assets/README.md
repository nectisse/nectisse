# 预览素材

`editorial-sheet.png` 从 `design/nectisse-visual-v1/assets/editorial-sheet.png` 原样复制，是第一版视觉方案用内置 imagegen 生成的虚构成年人物与摄影场景图集。生成提示词与原始说明保留在该设计目录。

`portrait-1.jpg` 至 `portrait-6.jpg` 是从图集中裁出的六张 418 × 627 图片，供共用正式页面的示例数据会话使用。原图集保留供本地回归脚本生成测试资料。

本轮没有重新生成、裁切或修改位图，使用 CSS 取景。素材随应用本地打包，既不获取站点封面，也不映射到真实作品或创作者。界面中的图片尺寸与来源标签均为模拟数据。
