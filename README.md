# Nectisse

把作品资料、喜欢的封面和关注的更新，收进自己的桌面空间。

Nectisse 是一款面向 macOS 的私人作品资料与创作者动态管理应用。查询感兴趣的作品，建立自己的收藏库，在同一处查看演员新作和创作者动态。

## 主要功能

- **作品资料查询**：通过编号、标题关键词或支持的原站链接，查询标题、人物、厂牌、发行日期、简介、标签与封面，查看不同来源的资料和原文。
- **作品磁链搜索**：在作品详情中按当前编号查询 Sukebei 或 JavTao，最多展示 20 条匹配结果，支持复制磁链和查看来源页面；也可打开黑马磁力首页自行搜索。
- **作品收藏**：保存作品资料与选定封面的原图，按编号、标题、人物、厂牌和标签搜索，按收藏时间、发行日期或编号排序。
- **照片墙浏览**：全屏拼贴收藏封面，支持拖动、缩放与搜索；点击预览原图或查看作品资料，返回时保留浏览位置。
- **演员与创作者关注**：集中查看新作、公告和制作进度，管理已读与未读，随时打开来源原文。
- **更新检查**：支持手动检查与定时检查，可以调整频率、暂停关注或取消任务。
- **个性化设置**：提供浅色与深色外观，自行选择来源并调整资料与封面的采用顺序。

资料来源涵盖 DMM / FANZA、JavTao、r18.dev、FC2、AVBase、一本道及部分片商官网；关注来源包括 FANBOX、JavDB、JavTao、X、Patreon 等。JavTao 支持按演员名或主页查询并关注新作；X 支持无需登录追踪公开账号的本人原创帖，不收录回复、引用和转发。

## 你的私人收藏库

收藏、关注、查询记录和已读状态保存在本机。收藏的资料与原图可以离线浏览，重新查询不会自动覆盖已保存的收藏，是否更新由你决定。

列表使用轻量缩略图，清晰原图在查看详情时按需获取。普通图片缓存默认上限为 512 MiB，可在“设置 → 网络与存储”调整或主动清理；收藏原图固定保留。清理图片不会删除资料、帖子摘要和已读状态，缺图时会尝试单独补取。

关闭窗口后，应用可以继续在后台检查更新；退出应用时停止任务。

## 平台与发布
